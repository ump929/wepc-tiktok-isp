## 原生 IP、住宅 IP、双 ISP，差的到底是什么

这三个词经常被混着用，实际是三层不同的东西。

**原生 IP**：IP 的归属地和服务器所在地一致，中间没做过转发或伪装。服务器在台北，IP 注册地也在台湾，就算原生。但原生只说明"地理对得上"，不说明"身份像不像人"。一个原生 IP 的 ASN 属性完全可能还是普通 IDC 机房段，TikTok 照样能识别出来，只是信任度比机场节点和公共云主机高一档。

**住宅 IP**：IP 来自真实的当地宽带运营商，比如美国的 Comcast、英国的 BT。这类 IP 在平台眼里自带"家庭用户"标签，因为它本来就是分配给住户的。

**双 ISP 住宅 IP**：在住宅 IP 的基础上再严一层，ASN 编号和 ASN 组织名两项都归属真实运营商，用 scamalytics 这类风控引擎查，欺诈分接近 0。这是目前 TikTok 环境里信任度最高的一档，也是最贵的一档。

所以"原生 IP"和"双 ISP 住宅 IP"不是同一个东西，价格差好几倍也正常。买之前至少要知道自己付钱买的是哪一档。

## 拿到 IP 之后，自己验一遍

商家页面写什么是一回事，IP 实际是什么属性是另一回事，尤其当你买的是"住宅""家宽"这类描述性标签。三个免费工具够用：

1. **scamalytics** 查欺诈分，接近 0 才算干净；
2. **ipinfo** 看 ASN 类型，usage type 显示 ISP 才偏向住宅，显示 Hosting 或 Data Center 就是机房段；
3. **whoer** 看 DNS 有没有泄露，DNS 落到别的国家，IP 再干净也会被关联异常。

三项都过，这条 IP 才算能用。有任意一项不过，别急着养号，先开工单问商家。

## FAQ

**一台 VPS 能同时运营几个 TikTok 账号？**

不建议超过一个。平台的风控逻辑是一账号一 IP 一设备，共用 IP 的账号容易被关联，出一个问题就连坐。矩阵运营的正确做法是多开低配机器。

**机房 IP 能不能做 TikTok 直播？**

技术上能推流，但平台把你判成数据中心之后，推荐和画质都会受影响，直播中断的概率也高。要长期做，住宅或原生 IP 是更稳的起点。

**1080P 直播需要多大带宽？**

推流码率 3–6Mbps，换算下来 10Mbps 上行就够一个 1080P 直播间。WePC 台湾线的 200Mbps 带宽完全不是瓶颈，选套餐时该看的是内存和 IP 属性。

**韩国那条线为什么写着 TK 直播却解不开 TikTok？**

第三方实测的结论是该 IP 属性为韩国原生但非住宅，TikTok 未解锁。产品命名和实测能力之间存在差距，买之前自己验 IP 是唯一可靠的办法。
